# Contributing to chgsmart

Thank you for your interest in contributing to **chgsmart**, a CLI tool written in Go. While the project is currently maintained by a solo developer, contributions are welcome to help improve and future-proof the tool.

## How to Contribute

1. **Fork the Repository**  
    Create your own fork of the project on GitHub.

2. **Clone Your Fork**  
    ```
    git clone https://github.com/your-username/chgsmart.git
    ```

3. **Create a Branch**  
    Use a descriptive branch name:
    ```
    git checkout -b feature/your-feature-name
    ```

4. **Make Changes**  
    Implement your changes, following Go best practices and idiomatic code style.

5. **Test Your Changes**  
    Ensure all tests pass and add new tests for your changes if applicable:
    ```
    go test ./...
    ```

6. **Commit and Push**  
    Write clear commit messages:
    ```
    git commit -m "Describe your change"
    git push origin feature/your-feature-name
    ```

7. **Open a Pull Request**  
    Submit a pull request on GitHub. Include a description of your changes and reference any related issues.

## Guidelines

- **Code Style**: Follow Go conventions (`gofmt`, `golint`).
- **Documentation**: Update documentation and comments as needed.
- **Issues**: Use GitHub Issues for bug reports, feature requests, or questions.
- **Code of Conduct**: Be respectful and constructive in all communications.

## Getting Help

If you have questions or need guidance, open an issue or contact the maintainer.
